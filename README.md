# Typing Voice

キーボードで入力した文章を、ブラウザの音声合成機能でその場で読み上げるシンプルなページです。

## 起動

```sh
python3 -m http.server 4176
```

ブラウザで <http://localhost:4176> を開きます。入力を少し止めると、確定済みの新しい文字だけを読み上げます。句読点・改行ではすぐに読み上げ、`Escape` キーで読み上げを止められます。

Chrome、Edge、Safariなど、Web Speech APIの音声合成に対応したブラウザで利用してください。日本語音声の種類や声質はOSとブラウザによって異なります。
